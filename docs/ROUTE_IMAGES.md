# 动线概念图对应关系

本组图用于解释空间设计，不代表已经完成建筑建模、设备安装或临床验证。概念图在各站介绍面板及相应的三维屏幕中出现。序厅、个人岛和离场站保留既有示意图；其余图由本轮附件转换为压缩 WebP，原始 PNG 不在网页中重复加载。

| 顺序 | 场景 | 网页图像 |
| --- | --- | --- |
| 00 | 院区序厅 | `assets/route/00-gallery.webp`；首页非三维设备的总览图为 `assets/route/overview.webp` |
| 01 | 形象入口 | `assets/route/01-avatar.webp` |
| 02 | 情绪感知与个人岛 | `assets/route/02-emotion.webp` |
| 03 | 生成式成长走廊 | `assets/route/03-growth.webp` |
| 04 | 圆桌 VR 剧本体验 | `assets/route/04-roundtable.webp` |
| 05 | 分叉与自主选择 | `assets/route/05-fork.webp` |
| 06 | 隐秘个人岛 | 既有舒缓舱示意 |
| 07 | 共创与社交 | `assets/route/07-cocreation.webp` |
| 08 | 镜映空间 | `assets/route/08-mirror.webp` |
| 09 | 回到日常 | `assets/route/09-cafe.webp` |
| 10 | 报告展示厅 | `assets/route/10-report-wall.webp`（整面数字墙）与 `assets/route/10-report-review.webp`（专业复核视角） |
| 11 | 下一次航程 | 既有再访示意 |

`tools/prepare-route-images.py` 保留附件到网页资产的转换关系；若不持有原始附件，已生成的 WebP 文件仍可直接部署。
