# 梓笙园 AI 体验中心 · 动线全景

根目录 `index.html` 是唯一主入口。`atlas/app.js` 用 Three.js 构造连续的三维建筑动线；`atlas/styles.css` 为界面。浏览器打开根目录即可看到一幅可拖动、旋转、缩放的全景，点击真实场景几何体或下方站点查看每一处的具体功能，点击「开始导览」按顺序自动走访。没有旧版 `genesis/` 的嵌入或旧版 `tour/` 白模入口。

## 本轮动线

院区序厅与机器人展览 → 形象入口 → 情绪感知与环形屏个人岛 → 生成式成长走廊 → 圆桌 VR 团体情境 → 两条平等支路（隐秘个人岛 / 共创社交）→ 镜映 → 回到日常的咖啡角 → 分层报告数字墙 → 下一次航程。分叉支路在全景中可见，选择后汇合；页面演示不接入任何真实患者数据。

## 美术与交互

参考用户视频的暗色空间、粒子雕塑、细线和局部暖光，但不复制视频画面。建筑有真实厚度，圆桌旁的粒子雕塑是局部物件；环形屏、VR 位、舒缓舱、镜面、院区沙盘和报告墙各有独立几何结构。没有乐高人物。概念图只贴在实体屏幕及信息面板，不充当整个三维空间的背景。

这仍是可交互的**概念可视化**，不应被称作按 CAD 精确还原的建筑模型或已验证的治疗系统。正式建设还需测绘、制作高精度模型与贴图、审定医疗信息和录制统一真人旁白。当前不使用浏览器合成语音冒充真人。人物视角与设备配置在评审时以原场地视频、尺寸资料和专业人员意见校正。

## 核对

- `node --check atlas/app.js`
- 本地静态服务器运行仓库根目录；桌面检查全景、12 处点击、两条支路、拖动和缩放；手机检查底部站点与信息面板。自动导览逐站显示对应概念图，报告厅展示两张不同视角。
- `atlas/` 不读取 `genesis/`、`tour/`、临床数据或旧旁白文件。若删除旧目录，确认其他部署入口没有引用后再统一清理。
