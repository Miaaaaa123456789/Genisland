# 梓笙园三维游览

`npm install && npm run build` 后，把 `dist/index.html`、`dist/app.js`、`dist/app.css`、`dist/audio/` 同步到根目录 `tour/`；宣传页地图下的同源 iframe 加载 `tour/index.html`。部署配置仍发布仓库根目录。`npm run dev` 可在 4173 本地预览。

## 现在可以检验的部分

同一幅可旋转、缩放、逐站靠近的 Three.js 场景包含连续屋架、金属与玻璃边界、站点仪器与青色航线；昼夜照明、漫游、低空飞行和画质开关均可操作。它是**技术与动线示意模型**，还不是截图所示 `zishengyuan.html` 的精细复刻；截图页面的源代码不在当前仓库。没有把九张概念图当成平面贴图伪装成三维。

点击「开启讲解」完成浏览器要求的首次音频授权。鼠标在可交互区域稳定悬停约 900 毫秒播放对应的中文预录语音；移出时 260 毫秒渐弱，快速扫过不会播。切站只有一段声音，父宣传页的视频与环境声通过同源 `postMessage` 避让。当前音频是现有普通话 Neural 语音初版，正式版需导演、录音和逐句审听；浏览器和系统仍可能阻止用户未授权的自动有声播放。

## 参考项目在代码里的对应点

- [brunosimon/folio-2025](https://github.com/brunosimon/folio-2025)：参考其按区域组织、单独管理资源与品质的方式；`src/world.js` 为各站生成独立 `Group`，`src/main.js` 异步加载各站 GLB 并控制画质和交互，未复制其车辆、风格或源码。下一阶段应使用按区加载的真实 GLB、KTX2、LOD、遮挡和性能档位。
- [MengTo/a-long-expected-party](https://github.com/MengTo/a-long-expected-party)：参考其章节声景与讲述声音调度；`src/voice.js` 管理站点延迟、排他播放和渐入渐出，宣传页脚本与视频／环境声互斥。当前尚未有专业配音、逐章音乐混音与人工听感验收。

## 资产交接

九站坐标、命名和模型路径在 `src/stations.js`，详见 `docs/ASSET_SPEC.md`。待办包括实地测绘比例、九个带厚度和细节的空间 GLB、人物与机器人动作、PBR 材质贴图、场景级光照和九段定稿配音。没有这些资产，程序几何不能达到参考仓库的写实完成度。概念参考图未获另行公开授权，因此不随仓库及发布包分发。
