# 三维空间制作工作台

`npm install` → `npm run dev` → `npm run build`。本目录是一个单独的 esbuild/Three.js 工程，发布目标尚未切换；根目录的宣传站继续照旧发布。开发预览为 `http://localhost:4173`。

## 已实现与待制作

已实现：透视镜头与平滑聚焦、旋转缩放、站点悬停高亮、顺序浏览、第一人称步行/低高度飞行、昼夜切换、移动端基本布局、降低像素比、GLB 异步加载、缺失资产提示，。九张概念图未随本次公开提交；将来获授权补入时只出现在 HTML 资料栏，不会贴到 Three.js 场景里冒充建筑。

待制作：按实地视频核对空间几何；九个带墙体厚度、门洞、天花、家具、装置、角色和灯光分组的 GLB；PBR 贴图与环境照明；分支转场、角色动作、场景生成策略；专业配音、音量避让；移动端实机优化。**目前看到的灰色地面和圆形标记是导航白模，不是最终视觉效果。**

## 模型交接协议

`src/stations.js` 声明 01–09 路径与模型 URL。把每站 `.glb` 放进 `public/models/`。模型局部原点是该站入口地面中心，Y=0 为地面，1 Blender unit = 1 metre，朝向统一；场景会在 `stations.js` 的暂定坐标处安放模型。可高亮构件节点名包含 `accent`，其他节点不整体发光。导出后核对人的视线高度约 1.5–1.7 米、圆桌与门洞比例、背面和遮挡关系。正式位置要由视频白模替换暂定坐标。

先完成 `01-arrival.glb`，确认实际材质、镜头、性能后再建其余八站。绝不能把一张生成概念图纹理铺在平面上伪装成 3D。详细规格见 [ASSET_SPEC.md](docs/ASSET_SPEC.md)。

## 参考项目的可迁移方法

- [Folio 2025](https://github.com/brunosimon/folio-2025) 把世界拆为独立区域和对象，使用 GLTF/DRACO/KTX2 加载、区域可见性、质量等级、独立渲染调度。借鉴**生产结构与优化方法**，不要照搬其游戏风格或车辆交互。
- [A Long-Expected Party](https://github.com/MengTo/a-long-expected-party) 使用章节时间轴、实时环境变化与同步旁白/氛围声/配乐，并在旁白时压低其他声道。借鉴**叙事节奏与音频调度**，不要把青少年体验做成无法主动探索的短片。

两者的完成度主要来自实际资产制作与反复调光、镜头、声音；代码框架不能凭空代替九站建模。
