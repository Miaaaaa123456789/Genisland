# 九站三维资产制作与视觉验收

## 真正的差距

现有仓库根目录是图片/视频宣传单页，尚未拥有九站的三维模型。参考作品的精细感来自模型结构、真实尺度、贴图、环境光、镜头、动作与声音共同设计。新增 `spatial/` 是可运行的技术白模，**不是已达到概念图效果**。先对照实地视频确认空间，再逐站制作实模型。

## 统一美术圣经

- 空间：真实建筑尺度、连贯曲面外壳、有厚度的墙/门/玻璃/桥，走近时可看到背面与接缝。开阔而有明确活动密度；外围深灰蓝退后，人物工作区保留足够亮度。
- 色材：深石墨色缎面金属、温润浅木吸音肋、暗灰水磨石、低铁玻璃和布艺；技术画面只用克制的青/淡紫，局部暖光作为视觉锚点。避免大面积荧光、过度镜面反射、均匀木条重复。
- 渲染：金属/粗糙度工作流；颜色纹理 sRGB，法线/粗糙度/金属度线性；环境 HDR 加局部实际灯具；接触阴影与柔影；曝光与色调映射一致。不可拿一张图片贴在正对镜头的平面上冒充空间。
- 镜头：全景 30–40 mm 等效透视，中近景 35–50 mm；人物真实比例。日夜两套灯具状态保持同一结构/站点/镜头。夜晚仍能辨认面部、门洞、路径和报告。
- 人物：一位固定的青少年访客贯穿九站，入口形象、衣饰、发型在镜映中可核对；镜映变化只影响姿态、本人确认的装饰或叙事物件，不自动判定“改善”。白色机器人头为圆角矩形，两个相连黑色圆镜片、双细天线、白色椭圆躯干、短臂，九站不得漂移成其他外形。
- 主动差异：第 02 站生成的线索延续到 03/04；04 的表达与选择影响 05 分支和 06 回顾；08 的自愿共创与 09 的下次线索衔接。场景可变但主体位置、临床目标和退出方式固定。

## 九张视觉母版与场景交付

| 文件 | 单站核心物件与行为 | 最低可审查建模内容 |
| --- | --- | --- |
| `01-arrival.webp` | 拍照/预设形象、服饰配件、机器人、院区地图 | 可走近相机/屏幕/隐私遮挡、机器人完整背面、院区台、通向 02 的门洞 |
| `02-personal.webp` | 自选经历的空间化线索 | 非固定插画墙；多个可替换内容载体、触摸台、可跳过路径、通向 03 的视线 |
| `03-emotion.webp` | 动作/声音/自述的情绪表达 | 传感区、局部投影表面、交互反馈、本人修正入口，避免漂浮诊断分数 |
| `04-roundtable.webp` | 六人左右的生成式人际情境 | 圆桌、座椅、真实人物比例、带领者、可见分支出口；无胜负闯关 UI |
| `05-branch.webp` | VR 练习／放松舱／直接通过 | 两间平等可选空间，治疗师位置、暂停/退出路径、围合式低刺激舱，最终汇合 |
| `06-mirror.webp` | 同一访客回看选择 | 有厚度的镜框、镜后空间、真实反射/受控替身镜像、同一身份，往 07 的出口 |
| `07-cafe.webp` | 沉浸到现实的缓冲 | 可坐可离的咖啡厅、不同声学/光照、往开阔区的连续可见通道 |
| `08-cocreation.webp` | 自愿共创/社交、机器人展示 | 开阔厅、可多人操作的实体桌、边缘产品陈列、独处位置、不同活动人群 |
| `09-report.webp` | 本人记录、专业评估、AI 整理分区 | 分权限屏幕、治疗师陪同、离场口、下次来访连续线索 |

## 文件与成本预算（初始目标，按实机调整）

- 每站一个 `public/models/NN-name.glb`；独立动画可另包。整体 1 Blender unit = 1 m，原点在入口地面，统一法线/尺度，非关键构件不要双面渲染。
- 细节优先给 01 的形象屏/机器人、04 的人物互动、05 的分支、06 的镜面、08 的共创桌、09 的报告。大面积房间需有结构、连接和合理重复，不要用九个圆柱体充数。
- 主视角资产 LOD0 有足够中近景结构，远处 LOD1/2 保留建筑剪影；纹理尽量压缩为 KTX2，模型使用可重复实例的共享材质。初始桌面目标 60 fps，中端移动目标 30 fps；完整场景三角形/绘制调用与显存需实测，不把任意固定数字当质量保证。
- 对每站交付 `.blend`、`.glb`、贴图来源/许可、单位/轴向、节点命名、白天与夜晚同机位图、人物尺度图、360° 旋转录像、模型统计。生成概念图属于**目标**，不能充作最终模型验收截图。

## 空间对应关系

`src/stations.js` 的坐标只是技术演示。实地视频中的入口、连续走廊、转角、咖啡厅与开阔区是待核对锚点。先绘关键帧与俯视白模并标注“视频确认/概念待确认”，确认后才调整坐标和门户。用户尚未在本仓库提供可供比对的精确 CAD 平面，不能伪称精确复刻。
