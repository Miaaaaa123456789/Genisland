# 接手制作指令：不要把白模当成最终效果

先阅读根目录 `README.md`、`AGENTS.md`，再阅读 `INTERACTION_WORLD_SPEC.md` 和 `ASSET_SPEC.md`。`spatial/src/world.js` 的重复几何控制台是等待真实资产替换的工作模型，不能照它复制九站。`tour/` 是宣传页地图下实际加载的发布包，修改 `spatial/` 后必须重建并同步 `tour/`。

目标是一座连续、开阔、真实尺度的未来医疗体验中心。空间必须可绕后观察，门洞、桥、墙、屋顶、家具和互动装置均有厚度。深石墨金属、浅木声学肋、暗灰水磨石、低铁玻璃与克制的青色投影形成统一材料语言；白天明亮，夜间保持路径和人物可辨。禁止九个相同展台、乐高几何、照片贴片和纯粒子背景冒充精细三维。

当前网页顺序以 `src/stations.js` 为准：01 入口形象与地图 → 02 产品与专业入口 → 03 生成走廊 → 04 共享航段 → 05 个人岛及可选低刺激空间 → 06 镜映 → 07 共创交流（经现实缓冲） → 08 报告展示 → 09 离场再访。原场地视频确定物理位置；若确认不同，记录依据并同步修改地图、三维、导览和文案。

先做 03→04→05 垂直切片：03 以授权选择和可复现 seed 改变岸线、线索、声景、人物回应；04 把同一条线索带入真实的多人互动；05 可自主进入、退出或跳过个人空间。固定建筑拓扑与专业目标。每次操作必须有三维物体反应、声音反馈、可撤回状态，不能只更换按钮文案。第 06 保持同一人物身份，第 07 共创桌可拖拽与撤回，第 08 报告区分体验记录、本人确认、正式评估和 AI 整理。

参考 [Folio 2025](https://github.com/brunosimon/folio-2025) 的区域资源生命周期与性能分级、[A Long-Expected Party](https://github.com/MengTo/a-long-expected-party) 的章节声景与音频调度；按 `INTERACTION_WORLD_SPEC.md` 的代码入口和验收证据落实，不复制原代码或美术。现有配音是合成试听，正式版需录制、审听和混音。

交付同机位昼夜全景、人物尺度与绕后录像、四次可复现生成的录屏、03→05 因果传播、06 身份连续、07 撤回、08 报告数据来源、语音与视频互斥、桌面/移动性能记录。若画面仍像白模，先修资产与灯光，不能靠新文案宣布完成。
