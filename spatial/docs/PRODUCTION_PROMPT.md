# 可直接交给制作模型的任务书

你正在维护 `Miaaaaa123456789/Genisland`。先阅读仓库根目录 `README.md`、`AGENTS.md`，本目录 `spatial/README.md` 和 `spatial/docs/ASSET_SPEC.md`；若制作环境能访问原设计会话，再对照其中的九张概念图；这些图尚未授权随本次代码和提示词公开上传，当前仓库中没有图像文件。没有图时以逐站文字规格为准，并将视觉核对列为待办，不能自称已经对照原图。根目录是既有宣传网站，**不要删除或覆盖**。`spatial/` 是新建的 Three.js 制作工作台，不是已经完成的三维网页。不要把旧图片热点页面误认为三维代码，也不要把现有白模当作最终美术效果。

目标是把九站设计做成**同一座可自由观察、可沿动线探索的写实未来医疗体验中心**。借鉴 [Folio 2025](https://github.com/brunosimon/folio-2025) 的区域模块化、GLB 资源加载、可见性与性能分级；借鉴 [A Long-Expected Party](https://github.com/MengTo/a-long-expected-party) 的章节节奏、环境变化及音乐/旁白避让。不要复制两个项目的代码、模型、字体、音频或场景美术；这不是赛车游戏，也不是只能看不能探索的自动播放短片。

首先分析原场地动线视频，截取入口、走廊、转角、咖啡厅、开阔区、离场处的关键帧，画出“视频确认”和“尚待确认”的空间关系。九站的行为顺序固定：01 入口定制同一虚拟形象 → 02 个人经历线索 → 03 情绪辨认/本人修正 → 04 带领的圆桌人际情境 → 05 临床适合者 VR 练习或低刺激休息或直接通过，三路汇合 → 06 镜映回看自己的具体选择 → 07 咖啡厅缓冲 → 08 自主共创/社交 → 09 分层报告与离场。再次来访时经授权延续本人选择的问题，场景和视角可变，但核心目标、身份连续性及临床边界不变。

画面采用真实建筑尺度，而不是桌面微缩、卡通低多边形、乐高或空旷商场：有厚度的深石墨曲面外壳、浅木声学肋、暗灰水磨石、透明但可看见边缘的玻璃、细腻布艺；屋顶漫射自然光、实际灯具暖光和局部克制的青/淡紫投影共同照明。外围深灰蓝暗下去以显空间纵深，走道/人物/活动区保持清楚。第 02/03 空间较亲近，04 圆桌打开，05 分支各有独立尺度，06 再收束，07 明暗与声音逐渐回到日常，08 空间真正开阔，09 平静而专业。九站不是九个并列功能展台，每一步都回答上一站留下的问题。

遵循 `ASSET_SPEC.md` 的模型命名与接口。优先把 **01 入口**做成完整垂直切片：真实建模的机器人、院区地图、屏幕、饰品、建筑连廊，PBR 材质、漫射环境光、灯具、人物尺度、进入 02 的视线、hover 高亮与近景镜头。交付日光全景、同机位夜景、人物尺度近景及可旋转录像。与概念图并排检查；若达不到材质、结构与空间密度标准，先改 01，不许把同一个简陋白模复制九次。通过后复用资产/灯光管线完成 02–09。

交互要求：第三人称透视全景可旋转、缩放、拖动；点击区域沿可理解的路径平滑靠近并能返回全景；鼠标停留时只高亮当前区域和下一段路径，移动端点按；步行/低空飞行可选。所有模式能识别当前位置和出口，避免穿墙。昼夜同一场景地标不移动。第 05 的三个选项空间真实分开并汇合。镜映中的形象始终是入口的本人形象，不出现无因的外观升级。共创作品只有经授权才可供其他人的下一次体验使用。

专业表达要求：CBT/DBT/人际技能等**方法的证据**与本体验中心**尚待验证的效果**分开；VR 暴露仅由专业人员评估与带领，随时暂停退出；睡眠舱不宣称一次改善睡眠。体验报告分开本人自述、可观察行为、正式临床评估、AI 整理，不把生成情节或形象变化写成诊断。风险信息不在公开演示中放真实患者数据。网页主画面简洁，循证解释按需展开并提供可核查的文献链接。

实施顺序：① 视频动线核对表及白模；② 01 单站高保真资产与验收；③ 九站资产与同一访客连续镜头；④ 生成规则、分支和回访状态；⑤ 三层声音（配乐/环境/解说）及 video 音频避让；⑥ 移动端和低性能降级；⑦ 发布前逐站截图与交互测试。每阶段保留可运行代码和资产来源，不以一张概念图、背景视频、漂浮粒子、CSS 滤镜或“待替换”盒子宣称完成。
